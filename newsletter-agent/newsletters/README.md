# Past newsletters

Put newsletters you've already sent here, one file per month
(`2026-09.md`, `2026-10.md`, ...). Plain text or Markdown both work.
The agent reads the most recent ones to match your style and to avoid
repeating the same tips and stories.

Drafts the agent writes are saved in `drafts/`. Once you've sent one,
move it up into this folder so next month's draft can learn from it.
