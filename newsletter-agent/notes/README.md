# Monthly notes

Before you run the agent, drop rough notes for the month in a file named
after the month, e.g. `notes/2026-11.md`. Bullet points are fine:

```
- Holiday schedule: closed Nov 27, open 8am-12pm Nov 28
- New Saturday youth class starts Nov 8, 10am
- Member spotlight: Maria hit 100 classes
- Price stays the same in 2027
- Food drive for the community pantry all month
```

No notes file? That's fine: the agent will interview you instead.
